How to use MAAT ETC

This page explains the basic workflow for estimating exposure time or signal-to-noise values with the MAAT Exposure Time Calculator.

Open calculator Back to home
1

Choose the compute mode

Select S/N to estimate the signal-to-noise ratio from an exposure time, or Texpo to estimate the exposure time needed for a requested signal-to-noise value.

2

Enter the target flux

Set the flux type, flux value and reference wavelength. For emission-line calculations, include the line width in FwhmA and use Breadth when a spectral breadth is required.

3

Define the observation setup

Pick the grating, moon condition and air mass. These values describe the instrument configuration and observing conditions used by the calculator.

4

Describe the source profile

Use pointsource with a seeing value for compact targets, or extended with an area value for extended sources.

5

Select the SED template

Choose Ones for a flat template, Pickles for a stellar template, or Blackbody and enter the temperature when the blackbody option appears.

6

Run the calculator

Press Run ETC. The result panel displays the generated signal profile and a text summary once the calculation finishes.

7

Read the output file

The output .txt file stores the computed spectrum. The first column is wavelength, the second is the scaled flux, the third is the noisy flux, and the fourth is either S/N or exposure time, depending on the selected compute mode.

Using a text file

You can upload a plain text file to fill the form automatically. Each line should use the field name, an equals sign and the value ending with #.

Download example file 
compute = SN#
texpoSN = 1200#
fluxtype = continuum#
fluxval = 1.0#
wvinflux = 6500#
grating = R1000R#
sedtemplate = ones#
moon = dark#
airmass = 1.2#
psf = pointsource#
seeing = 0.8#
area = 1#
redz = 0#
breadth = 0#
fwhmA = 3#
